# Low Ticket (skills para Claude Code)

Esteira completa para criar uma oferta low ticket: oferta, copy da página, página de vendas, vídeos, criativos e banner de checkout.

## Instalar

No Claude Code:

```
/plugin marketplace add vissiacompany-ship-it/low-ticket
/plugin install low-ticket@vissia-low-ticket
```

Reinicie o Claude Code. Para começar uma oferta do zero, peça `lt-nova-oferta`.

## Skills

- `lt-nova-oferta`: conduz todas as etapas
- `lt-oferta`, `lt-copy-pagina`, `lt-pagina`
- `lt-video-passos`, `lt-video-demo`
- `lt-criativos-imagem`, `lt-criativos-video`
- `lt-banner-checkout`

O `playbook/` tem o método completo em HTML.

Obs.: alguns exemplos citados nas skills (pasta `fontes/`) não estão neste repositório.
